# FPP Overlay Effects 1.0.0

A complete rebuild of fpp-WledEffects as **FPP Overlay Effects**, designed for **FPP 10.4+** and FPP’s native effect engine.

## Install link

**[Copy this plugin installation URL](https://raw.githubusercontent.com/ravenridgelights-turtle/FPP-Overlay-Effects/main/pluginInfo.json)**

```text
https://raw.githubusercontent.com/ravenridgelights-turtle/FPP-Overlay-Effects/main/pluginInfo.json
```

1. Open **Content Setup → Plugin Manager** (called **Plugins** on some FPP versions).
2. For an unlisted plugin URL, FPP 10.4 requires the **Developer** User Interface Level. Set that temporarily in Settings if the URL field does not load plugin information.
3. Paste the URL above into the plugin search / URL field, load it, and click **Install**.
4. Refresh the browser and open **Status/Control → FPP Overlay Effects**. Refresh the normal FPP Status page to load the bubbles.
5. No extra packages, reboot, or plugin daemon are needed. Restore your preferred UI level after installation if desired.

The attached ZIP is a source archive; **use Plugin Manager and the URL above for normal FPP installation**.

## How to use it

1. Select your models, submodels, groups, or buffer views in **Lights & models**. Use search and filters to find the right target. Selecting a parent does not select its children.
2. Choose **Solid Color**, a native FPP effect, or a built-in **WLED** effect. Each effect loads its own arguments, sliders, palettes, and color slots from FPP.
3. Pick a color slot, use the wheel or hex entry, and adjust brightness and effect options. RGBW models expose a separate white-channel slider; single-channel models use intensity.
4. Press **Apply**. For live control, enable **Live changes**, then press Apply once. A completed drag/edit sends an update. Changing targets, stopping, loading a preset, refreshing, or leaving the tab disarms live output.
5. **Stop selected** releases only those overlays back to the show. It leaves playlists, music, and other targets running.
6. Save a named preset to keep a look and its targets on the FPP. Loading a preset never starts lights: review it and press Apply. Stars save favorite effects.

On phones, switch between **Colors / Effects / Models / Presets**.

## Status bubbles

While FPP reports running overlay effects, its normal Status page shows compact **prop / effect / Stop** bubbles. Multiple effects wrap neatly; **Stop shown** releases all displayed targets. The last stopped/finished effect hides the entire panel. No empty box remains. Bubbles coexist with After Show Hours Radio and remain available while a sequence is playing.

The display follows FPP’s real running-effect API. Static fills are not running effects and do not create bubbles; release a fill with **Stop selected** in the plugin.

## Pixel order and hardware

The plugin reads local pixel-string configuration and shows **port, receiver, virtual string, protocol, wire order, and channels per node**. FPP performs the actual RGB/GRB/RGBW/WRGB wire mapping, so the plugin never swaps colors twice. Different compatible model types may be selected together; detected node-width mismatches block Apply with a useful message.

For a separate network controller, configure its pixel protocol and wire order on that controller. FPP cannot reliably discover those physical settings over ordinary channel-output protocols. Inherited or unknown mappings are labeled accordingly.

## Upgrade from the original plugin

Stop effects in fpp-WledEffects, install this separately, and use its new menu entry. Its settings file is separate. Remove the old plugin through Plugin Manager if no longer needed. Old FPPMobile shortcuts that hard-code the original plugin name will need a separate app update.

## Validation

Checked against the November 9 FPP 10.4 source and automated command-contract, PHP metadata, and browser integration tests using simulated FPP responses. **Physical-light testing is still required**; begin with one prop at low brightness and check red, green, blue, and RGBW white. Later FPP versions use runtime effect discovery while their API contracts remain compatible.
